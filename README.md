# dsh-wsl-distro

DeepSeek Harness plugin: current WSL distro facts and multi-distro warnings.

## Install

```sh
dsh plugin --profile web add github:173787247/dsh-wsl-distro
```

Restart `dsh web`. Tool / feature: `distro_info`.

Part of **[dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit)**.
